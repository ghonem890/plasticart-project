# Plasticart

Plasticart connects Egyptian buyers with verified plastic packaging sellers. Explore a marketplace of plastic and packaging products from verified suppliers, compare options, and discover eco-friendly packaging solutions.

## Setup Instructions

1. Install dependencies:
   ```sh
   npm install
   ```

2. Start the development server:
   ```sh
   npm run dev
   ```

## Technologies Used
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vite
